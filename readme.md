# The Intention App

Big Brother did it first.

<img src="theintentionapp.png">

Displays an intention full screen on the mobile device. Big Brother style.

The app is designed to be used an always on reminder when completing tasks.

The intention application talks to a publically available REST API hosted on my private servers to fetch the latest intention from the server.

The intention on the server is managed by a web application that allows updating the intention to modify the phone display.

### The REST API backend

written in java with the spring framework.

<a href="https://github.com/softwareshinobi/the-intention-app-api">Backend REST API Code In GitHub</a>
